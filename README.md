## ⚡ Featured Project

### 🛡️ [SentinelMCP — Local-First AI Security Proxy](https://github.com/mbilalnasir751/SentinelMCP)
An asynchronous security middleware proxy built to protect token budgets and prevent data leaks. It intercepts outbound LLM requests from autonomous agents, sanitizes high-entropy strings (secrets) via Shannon entropy analysis, and triggers a rolling-window circuit breaker to stop recursive loop cycles[cite: 3].
*   *Built with FastAPI, Asyncio, SQLite (WAL mode), and Rich*[cite: 3].
